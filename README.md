## About this site

Static pages built with [Jekyll](https://jekyllrb.com) and served by GitHub Pages. Content is plain Markdown; the layout and styling are hand-written, with no theme gem and no third-party fonts, scripts, or trackers.

To run it locally:

```sh
gem install jekyll jekyll-seo-tag jekyll-sitemap
jekyll serve --livereload
```

Then open <http://localhost:4000/docs/>.
